# Tiered Curriculum: Foundations → Practitioner → Advanced/Champion

A single one-size-fits-all AI training session fails almost everyone in the room — it's too basic for your power users and too fast for everyone else. This curriculum is built as three deliberate tiers, each with its own objectives, so people opt in (or get assigned) to the depth that matches their role.

Use the **Readiness Snapshot** from the needs assessment to decide where each group starts.

---

## Tier 1 — Foundations
*Audience: everyone. Duration: ~2–3 hours, single or split session.*

**Learning objectives**
- Understand what generative AI is (and isn't) in plain language
- Write a clear, specific prompt using a simple repeatable framework
- Recognize the organization's AI usage policy and why it exists
- Know what should never be pasted into an AI tool (data privacy basics)

**Sample session outline**
1. Hook: a live "before/after" prompt example relevant to their daily work
2. What generative AI actually does (5 minutes, no jargon)
3. The prompting framework: Task → Context → Format → Evaluate → Iterate
4. Guided practice: everyone writes and refines one real prompt for their own role
5. Responsible use: the org's policy, in plain terms, with real examples of what not to do
6. Close: one thing to try before the next session

**Practice activity:** Each participant leaves with one working prompt template for a task they actually do weekly.

---

## Tier 2 — Practitioner
*Audience: staff who use AI tools regularly in their role. Duration: ~4–6 hours across 2–3 sessions.*

**Learning objectives**
- Build structured, reusable prompt workflows (including simple JSON-style outputs where relevant)
- Evaluate AI output for accuracy, bias, and appropriateness before using it
- Automate one real recurring task using an AI-assisted workflow
- Understand basic limitations: hallucination, outdated knowledge, inconsistent tone

**Sample session outline**
1. Recap + troubleshoot: what worked, what didn't, from Tier 1 practice
2. Structured prompting: templates, variables, and consistent formatting
3. Output evaluation: a simple checklist for "is this good enough to use?"
4. Hands-on lab: automate one real task end-to-end
5. Peer review: swap outputs, critique against the evaluation checklist

**Practice activity:** Submit one automated workflow (before/after time saved) as a portfolio piece for their own performance review.

---

## Tier 3 — Advanced / Champion
*Audience: power users identified in the needs assessment, future internal trainers. Duration: ~6–8 hours + ongoing coaching cadence.*

**Learning objectives**
- Design multi-step prompt chains and more complex LLM-assisted workflows
- Understand embeddings and retrieval at a conceptual level (why "search" beats "guessing" for factual tasks)
- Run structured evaluation and stress-testing on AI outputs (accuracy, coherence, safety)
- Coach and support colleagues informally as an internal AI champion

**Sample session outline**
1. From single prompts to workflows: chaining and multi-step design
2. Conceptual intro to embeddings/retrieval — when and why to use it
3. Building a stress-test: writing edge cases that break a prompt on purpose
4. Coaching skills: how to help a frustrated colleague without doing it for them
5. Champion network kickoff: cadence, shared channel, escalation path

**Practice activity:** Each champion adopts one department and runs a 30-minute Tier 1 refresher themselves, observed and coached.

---

## Progression logic

```
Foundations (all staff)
      ↓  self-selects or is assigned based on role
Practitioner (regular AI users)
      ↓  identified via needs assessment + demonstrated practice
Advanced / Champion (power users, future trainers)
```

Champions from Tier 3 become co-facilitators for future Tier 1 cohorts — this is what makes the program scale past what one enablement lead can deliver alone.
